# Simple Interest Calculator

## Description

This project is a simple interest calculator. It calculates the simple interest using the principal amount, rate of interest, and time.

## Formula

**Simple Interest = (P × R × T) / 100**

Where:

* **P** = Principal Amount
* **R** = Rate of Interest
* **T** = Time

## Example

If:

* Principal = ₹10,000
* Rate = 5%
* Time = 2 years

Then:

**Simple Interest = (10000 × 5 × 2) / 100 = ₹1,000**

So, the **Simple Interest is ₹1,000**.

## Features

* Easy to use
* Calculates simple interest quickly
* Uses the standard simple interest formula

## How to Use

1. Enter the principal amount.
2. Enter the rate of interest.
3. Enter the time period.
4. Calculate the simple interest.
